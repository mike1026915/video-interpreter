# 影片口譯側欄（Chrome 擴充功能）

擷取目前分頁的影片聲音 → 本機 Whisper 語音辨識 → Chrome 內建翻譯轉繁體中文 → 顯示在側邊欄。
全部在你的電腦上跑，免費、不需要任何 API 金鑰，聲音不會上傳。

## 安裝
1. 解壓縮到一個固定的資料夾。
2. 打開 `chrome://extensions`，右上角開啟「開發人員模式」。
3. 按「載入未封裝項目」，選這個資料夾。
4. 建議把擴充功能釘選到工具列。
5. 之後改了程式，在擴充功能卡片上按重新整理即可。

需求：桌面版 Chrome 138 以上。有獨立或內建 GPU（支援 WebGPU）會快很多。

## 使用
1. 打開有影片的分頁，點工具列上的擴充功能圖示 → 右側出現側邊欄。
2. 選原文語言和辨識模型（原文語言預設為日文），按「開始口譯」。
3. 播放影片。大約每 3～10 秒會出現一段原文，隨後補上中文。
4. 「匯出」可以下載逐字稿 .txt。

第一次使用會下載模型：Whisper small 約 300MB，翻譯模型每個語言對一個，之後都有快取。

### 辨識模型怎麼選
| 模型 | 適合 |
|---|---|
| base | 沒有 GPU，或速度跟不上時 |
| small | 預設，一般建議 |
| large-v3-turbo | 有 WebGPU 的顯卡時最準；下載量較大 |

### 整句翻譯
日文常把一句話拆在好幾段音訊裡，單段翻譯會失去上下文。所以：
- 辨識出的原文會**立刻顯示**，譯文則等到句尾標點（。！？）才把累積的幾段原文合併成一句再翻譯。
- 被合併的段落左邊會有色條，上面幾段標示「↓ 與下方合併成一句翻譯」，譯文顯示在最後一段。
- 以下情況不會再等：累積超過 80 字、已合併 4 段、或 3.5 秒沒有新的一段。按「停止」時也會把還沒湊成句的原文翻掉。
- 代價是譯文會比原文晚出現，晚多少取決於整句講多久。

### 看哪裡慢
每段時間旁會顯示各階段耗時，同樣的資料也會印在側欄 DevTools 的 console（`[timing]`）：

`00:18 · 音訊4.3s · 排隊0.0s · 辨識0.8s · 等句尾2.1s · 翻譯0.1s`

- **排隊**持續變大：辨識跟不上，改用較小的模型。
- **辨識**：模型推論時間。
- **等句尾**：為了湊成整句多等的時間（只有合併多段時才有）。
- 模型載入後會先用靜音預熱一次，所以第一段不會特別慢。

## 注意事項
- 換到別的分頁要用時，要在那個分頁再點一次圖示（Chrome 的權限限制）。
- 影片分頁重新整理或換頁後，擷取會中斷，需要再點一次圖示、再按「開始口譯」。側欄本身不用重新整理。
- 側邊欄關掉就會停止擷取，已顯示的逐字稿也會消失，需要的話先匯出。
- 「自動偵測」語言時，翻譯模型下載需要點一下側欄裡出現的提示按鈕。
- 背景音樂很大聲的影片，辨識品質會下降；有 DRM 的串流平台可能抓不到聲音。
- 沒有 WebGPU 時會退回 CPU（wasm），明顯比較慢。manifest 設了跨來源隔離，讓 CPU 模式可以開多執行緒；如果模型下載或載入出現跨來源（COOP/COEP）錯誤，刪掉 `manifest.json` 裡 `cross_origin_embedder_policy` 與 `cross_origin_opener_policy` 兩行即可，程式會退回單執行緒。
- Chrome 內建翻譯只能單句翻，詞義錯誤（例如人名、地名、多義詞）無法完全避免。

## 可調參數
`sidepanel.js` 最上面：
- 切段：`MIN_SEG_S`、`MAX_SEG_S`、`END_SILENCE_S`，以及超過 `LONG_SEG_S` 後改用的 `LONG_END_SILENCE_S`、靜音門檻 `SILENCE_RMS`。
- 整句合併（在「句子合併」區塊）：`MAX_GROUP_CHARS`、`MAX_GROUP_SEGS`、`GROUP_IDLE_MS`。

`asr-worker.js`：`max_new_tokens`、CPU 模式的執行緒數。
