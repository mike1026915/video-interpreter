# 影片口譯側欄（Chrome 擴充功能）

擷取目前分頁的影片聲音 → 本機 Whisper 語音辨識 → Chrome 內建翻譯轉繁體中文 → 顯示在側邊欄。
全部在你的電腦上跑，免費、不需要任何 API 金鑰，聲音不會上傳。

## 安裝
1. 解壓縮到一個固定的資料夾。
2. 打開 `chrome://extensions`，右上角開啟「開發人員模式」。
3. 按「載入未封裝項目」，選這個資料夾。
4. 建議把擴充功能釘選到工具列。

需求：桌面版 Chrome 138 以上。有獨立或內建 GPU（支援 WebGPU）會快很多。

## 使用
1. 打開有影片的分頁，點工具列上的擴充功能圖示 → 右側出現側邊欄。
2. 選原文語言和辨識模型，按「開始口譯」。
3. 播放影片。每講完一句（約 3～15 秒）會出現一段原文＋中文。
4. 「匯出」可以下載逐字稿 .txt。

第一次使用會下載模型：Whisper small 約 300MB，翻譯模型每個語言對一個，之後都有快取。

## 注意事項
- 換到別的分頁要用時，要在那個分頁再點一次圖示（Chrome 的權限限制）。
- 側邊欄關掉就會停止擷取。
- 「自動偵測」語言時，翻譯模型下載需要點一下側欄裡出現的提示按鈕。
- 背景音樂很大聲的影片，辨識品質會下降；有 DRM 的串流平台可能抓不到聲音。
- 速度跟不上時，側欄會提示，改用 base 模型即可。

## 可調參數
`sidepanel.js` 最上面：切段長度、靜音門檻等。
